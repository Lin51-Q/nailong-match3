# 奶龙素材说明

本版使用用户在 `image/` 提供的八张图片，没有接入 AI 生成形象。

原图不修改。`assets/source/` 保存统一透明画布 PNG；`public/assets/` 保存实际加载的 WebP；对应关系见 `public/assets/manifest.json`。

| ID | 游戏用途 |
|---|---|
| chill | 呆呆龙棋子、失败结算 |
| think | 思考龙棋子、教学 |
| smug | 得意龙棋子、进度头像 |
| happy | 快乐龙棋子、暂停 |
| laugh | 狂笑龙棋子、胜利结算 |
| pink | 粉粉龙棋子 |
| rainbow | 彩虹特殊棋子 |
| hero | 首页、游戏侧栏完整角色 |

表情名称按实际提供的图片调整，并没有把普通表情标为图片中不存在的“生气”或“委屈”。原始图片清晰度不同，转换不能恢复不存在的细节。圣诞帽图片采用保守背景处理，避免误删帽子的白色部分。

重新处理：安装 Pillow 后运行 `python tools/prepare_assets.py`。脚本也支持项目内 `.tools/python` 的 Pillow。自动生成尺寸统一的图片和预览；替换原图时同时调整脚本中的裁切范围。

棋子源图为 512×512，网页图片为 256×256；首页角色源图为 768×768，网页图片为 512×512。网页图片合计 66,280 字节。
