| 6—10 | 100%、99%、100%、94%、96% | 11.9、13.1、15.4、16.9、18.4 |

模拟中每次操作后检查棋盘满盘、没有未结算匹配、未结束关卡仍有有效操作。原始数据见 `docs/simulation.json`。没有出现无法结束的连消或无法继续操作的棋盘。

未修改难度数值：前五关为快速教学，收集与双目标关卡逐渐增加操作量。通过率只反映这个简单策略，不能等同真实玩家通过率；浏览器整局自动操作也不能替代玩家的主观试玩反馈。

## 资源与性能

网页奶龙图片合计66,280字节；主程序gzip约12.84KB，CSS gzip约4.98KB，使用系统字体。本地构建远低于3MB首屏资源上限。

动画模式下测量环境为 Windows 11、Intel Core Ultra 7 255HX、无头 Chromium 153.0.8010.12，1440×1000视口。执行7次游戏操作，8秒采样481帧，平均帧间隔16.64ms、P95为16.8ms，估计60.1FPS，没有页面错误。原始结果见 `docs/performance.json`。它只说明该环境的表现，不代表真实手机或所有设备性能。
