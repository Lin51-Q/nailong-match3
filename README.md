# 奶龙消消乐 · 这波我熟！

使用用户提供的奶龙图片制作的中文三消网页游戏。20关、特殊棋子、冰块、免费道具、手机操作和本机存档，纯前端运行。

## 开始玩

公开网址尚待 GitHub 登录后发布，不能把本地地址当成公开网址。

开发电脑安装 Node.js 24，然后在项目目录执行：

```sh
npm ci
npm run dev
```

打开控制台显示的本地地址。玩家访问发布网址不需要 Node.js 或任何安装。

## 检查与构建

```sh
npm run typecheck
npm run test
npm run simulate
npx playwright install chromium webkit
npm run build -- --base=/nailong-match3/
npm run test:e2e
npm run preview -- --base=/nailong-match3/
```

浏览器测试使用生产构建，覆盖 Chromium 电脑、Chromium 手机模拟、WebKit 手机模拟和本机 Edge。没有安装 Edge 时，可选择前三个项目运行。测试输出截图位于 `docs/screenshots/`，难度模拟见 `docs/simulation.json`。

直接双击源码的 HTML 不支持模块加载。使用本地服务或公开网址。

## 操作与规则

- 点击相邻两格或滑动交换；横竖三连消除，普通无效交换不扣步数。
- 横四连出横火箭，竖四连出竖火箭，T/L匹配出炸弹，五连出彩虹。
- 火箭和炸弹与邻居交换即可激活，彩虹消除邻居颜色；两只彩虹清全盘。
- 特殊效果会递归触发，但同轮不重复消除、计分或破冰。
- 每局一把小锤子和一次洗牌，免费且不扣步数；没有有效走法自动免费洗牌。
- 全部目标完成才过关，最后一步完成也判胜。
- 重玩和重试都补满道具。没有体力、付费、账号或在线排行榜。
- 进度、最好分数、星级和设置保存在当前浏览器；不会同步其他设备。刷新中途关卡返回首页。

## 修改关卡与素材

关卡配置集中于 `src/game/levels.ts`，共有20关。调整步数和目标后重新运行规则测试、模拟和整局浏览器测试。当前数值保持用户计划，没有为提高模拟通过率修改配置。

素材对应、尺寸和原图边界见 [素材说明](docs/ASSETS.md)。六种表情通过图片、底色和角标区分。替换图片后运行素材脚本，保留透明背景。

游戏规则集中于纯 TypeScript 引擎，不依赖界面。种子可通过网址的 `?seed=100` 重现棋盘；它不解锁关卡或修改进度。正式版本无作弊按钮和调试全局对象。

## 发布到 GitHub Pages

默认公开仓库名：`nailong-match3`。将本项目推送到 GitHub 后，在仓库 Settings → Pages 将 Source 设置为 GitHub Actions。已包含自动测试、构建和发布工作流。

工作流自动按真实仓库名称设置基础路径。构建产物在 `dist/`，站点资源全部随网站发布，不依赖图片外链或CDN字体。

发布后应等待 Actions 和 Pages 完成，从部署结果取得真实网址，再检查首页、图片、触屏、通关、刷新和本机进度。只有完成这些检查才可以报告公开发布成功。

## 验证边界
